# Haniff & Hanini - Digital Wedding Invitation & RSVP (#HaniNeedAHaniff)

A mobile-first, interactive digital wedding invitation and RSVP web application designed specifically for **Haniff & Hanini** for their reception (*Majlis Bertandang / Walimatulurus*) on **24 January 2027** at **Dewan Peladang Panji, Kota Bharu, Kelantan**.

## 🎨 Design & Aesthetic
Built based on the **"Whimsical Pink"** theme:
- **Palette**: Ivory cream (`#FAF3ED`), Berry Rose (`#A62053`), Dusty Pink (`#D8728D`), Gold (`#D4A359`).
- **Typography**: Playful whimsical handwriting (*Caveat*, *Sacramento*) paired with clean modern sans (*Plus Jakarta Sans*).
- **Custom Illustrations**: Curtains, chandeliers, vinyl record player, bismillah, house icon, doodle photo frames, and couple window.

## ✨ Features
1. **Interactive Curtain Splash**:
   - Left and right curtains slide open smoothly when the guest taps **"Open Invitation"**.
   - Triggers background music autoplay upon guest interaction.
2. **Personalized Guest Links**:
   - Append `?to=Nama+Tetamu` to the URL (e.g., `https://domain.com/?to=Encik+Ahmad+Faris`) to display a personalized invitation badge on the cover.
3. **Vinyl Record Audio Player**:
   - Vinyl record spins while playing and pauses with user control.
   - Persistent floating audio toggle button while scrolling.
4. **Countdown Timer**:
   - Real-time countdown (Days, Hours, Minutes, Seconds) to 24 January 2027.
5. **Event Details & 1-Click Navigation**:
   - Direct links to **Google Maps** and **Waze** for Dewan Peladang Panji, Kota Bharu.
   - **Add to Calendar** shortcut (Google Calendar).
6. **Photo Gallery & Lightbox**:
   - Responsive photo collage showcasing the couple's pre-wedding photography.
   - Fullscreen interactive lightbox modal with swipe/arrow navigation.
7. **RSVP & Ucapan (Guestbook)**:
   - Form fields: Name, WhatsApp number, Attendance (Hadir / Tidak Hadir / Belum Pasti), Pax count, and Message.
   - Festive confetti burst animation upon submission.
   - Live guest wishes message board.
8. **Digital Gift & Salam Kaut**:
   - Collapsible gift drawer with 1-click copy for bank account numbers (Maybank & Bank Islam).

## 🚀 Running the Project

### Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build & Serve
```bash
npm run build
npm run start
```

## 🌐 Deploy to Vercel (1-Click)
1. Push this repository to GitHub.
2. Import the repository in [Vercel](https://vercel.com).
3. Framework preset is automatically detected as **Next.js**.
4. Click **Deploy**!
